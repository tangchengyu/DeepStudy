# 长期任务三层交互设计

日期：2026-07-22
适用仓库：`deepstudy-vue`

## 目标

在保留现有艾森豪威尔四象限总览的基础上，为长期任务增加“象限列表”和“任务详情”两层页面，使用户能够快速浏览一个象限中的全部任务，并完整阅读任务备注。

本次改动必须兼容现有任务数据、提醒、拖拽排序、右键菜单、AI 拆解和跨窗口刷新行为，不修改长期任务 JSON 的版本和字段结构。

## 页面层级

### 1. 四象限总览

- 保留当前 2×2 四宫格布局与现有绿色视觉风格。
- 每个象限显示罗马数字、象限名称、未完成任务数量和进入图标。
- 点击象限标题区域或进入图标，打开该象限的单列任务页。
- 象限中的任务继续支持勾选完成、拖拽排序、跨象限拖动和右键菜单。
- 点击任务标题打开任务详情；点击勾选框只完成任务，不触发页面跳转。
- 有备注的任务显示笔记标识，便于在总览中识别。

### 2. 象限列表

- 顶部提供返回按钮、象限名称、未完成任务数量和新增按钮。
- 任务以单列列表展示，空间优先分配给标题，不再受四宫格卡片宽度限制。
- 勾选框用于完成任务；标题区域用于进入任务详情。
- 有备注的任务显示笔记标识，有提醒的任务显示提醒信息。
- 列表内继续支持拖拽排序、右键编辑、复制、移动象限、加入今日和删除。
- 在该页新增任务时，默认使用当前象限；用户仍可在编辑窗口中修改象限。

### 3. 任务详情

- 顶部提供返回按钮、所属象限和操作菜单。
- 完整显示任务标题和备注；备注使用纯文本呈现并保留原有换行，不截断内容。
- 显示提醒时间、创建时间或其他已有元数据；不存在的信息不占位。
- 提供完成、编辑和更多操作入口。编辑继续复用现有任务编辑窗口，避免产生两套表单逻辑。
- 任务没有备注时显示简洁的“暂无备注”空状态和编辑入口。
- 编辑保存后留在详情页并刷新内容；任务被完成或删除后返回原象限列表。

## 导航与状态

长期任务窗口维护仅存在于当前窗口会话的视图状态：

- `board`：四象限总览。
- `quadrant`：单个象限列表，并记录当前象限。
- `detail`：任务详情，并记录当前任务 ID 和来源象限。

该视图状态不写入磁盘。重新打开长期任务窗口时从四象限总览开始。

返回规则：

- 详情页返回来源象限列表。
- 象限列表返回四象限总览。
- `Esc` 或平台常用后退快捷键在没有打开弹窗时执行同样的返回行为。
- 编辑弹窗、AI 面板等临时界面优先处理自己的关闭操作。

当任务通过提醒、主窗口或其他操作发生变化时，当前视图重新读取任务列表。若详情任务已不存在或已完成，则安全返回其象限列表；若只是编辑，则原地更新详情。

## 数据与安全

- 继续使用现有任务字段，包括 `id`、`title`、`notes`、`quadrant`、提醒和排序字段。
- 不修改长期任务文件版本，不迁移、不删除已有数据。
- 详情页通过 DOM 文本内容和 `white-space: pre-wrap` 显示备注，禁止将备注作为 HTML 注入。
- 遵守当前 CSP，不添加内联脚本、远程资源或不安全的 HTML 渲染。

## 交互冲突处理

- 勾选框、菜单和按钮必须阻止事件冒泡，避免误打开详情。
- 拖拽结束后的点击不得触发详情跳转。
- 任务标题和象限入口使用可聚焦的语义化按钮或等效键盘交互。
- 焦点样式、按钮标签和颜色对比度应保持清晰。

## 实现范围

主要修改：

- `renderer/long-tasks.html`：增加总览、象限列表、任务详情三个视图容器。
- `renderer/long-tasks.js`：增加导航状态和三种渲染函数，复用现有任务操作。
- `renderer/long-tasks.css`：增加列表页、详情页、笔记标识和响应式样式。
- `renderer/long-task-utils.js`：仅在需要抽取可测试的纯函数时修改，不改变持久化结构。
- 相关测试和 Electron 冒烟脚本：覆盖导航、备注显示及原有操作回归。

不在本次范围：账号系统、云同步、移动端页面和网关实现。这些工作在两个桌面版本完成发布后开始。

## 验收标准

1. 四象限总览继续正常显示、滚动、拖拽和完成任务。
2. 四个象限都可独立进入对应的单列列表，列表任务和数量准确。
3. 点击任务标题可进入详情，备注完整显示并保留换行；恶意 HTML 只作为文本显示。
4. 勾选框、拖拽和菜单不会误触发详情导航。
5. 编辑任务后详情即时更新；完成或删除任务后返回正确的象限列表。
6. 旧版长期任务文件无需迁移即可正常使用，其他桌面功能不受影响。
7. 两个仓库采用一致的交互和数据行为，并通过现有自动测试与 Electron 冒烟验证。
8. 版本升级为 `1.2.11`，Windows 安装包和 macOS DMG 发布到各自 GitHub Release。
9. `deepstudy-vue` 的 Windows 桌面快捷方式指向本次构建的可执行文件。

## 风险与缓解

- 拖拽与点击冲突：记录拖拽状态并在拖拽结束后的点击周期内抑制导航。
- 详情对象失效：每次渲染按任务 ID 从最新列表取值，不持有过期对象引用。
- 两仓库实现漂移：以相同测试用例和关键文件差异检查保证行为一致。
- 发布平台差异：Windows 在本机验证，macOS DMG 由 GitHub macOS Runner 构建并验证 Release 资产。

# 长期任务详情提醒与本地图片设计

日期：2026-08-03
适用分支：`本地版本`

## 目标

让用户在长期任务详情页直接维护提醒方式和提醒时间，并让 Obsidian 风格的 Windows 本地图片引用能够被导入、持久保存和正常显示。

## 详情页提醒设置

- 在任务元数据与 Markdown 笔记之间增加可折叠的“提醒设置”区域。
- 收起状态显示当前提醒摘要；展开状态提供“不提醒、单次、每天、每周”四种方式。
- 单次提醒显示日期和时间；每天提醒显示时间；每周提醒显示时间和星期选择。
- 字段变化沿用详情页现有的 500 毫秒自动保存，不再打开旧任务编辑窗口。
- 单次提醒必须晚于当前时间；每周提醒至少选择一天。验证失败时保留用户输入，并在组件内显示对应语言的错误信息。
- 提醒保存后继续使用现有 `reminder` 数据结构、后台轮询和系统通知，不迁移任务文件。

## Obsidian 本地图片导入

- Markdown 行渲染器识别 `![[C:\\path\\image.png]]` 和 `![[C:/path/image.png]]`。
- 渲染器不直接加载 `file://` 地址，而是通过受限 IPC 请求主进程导入图片。
- 主进程只接受绝对本地路径，并复用现有图片扩展名、大小上限和应用图片目录校验。
- 导入成功后将图片复制到 DeepStudy 的长期任务图片目录，并把该行替换为现有的 `deepstudy-image://<id>` 引用，然后触发自动保存。
- 同一路径在一次页面会话中只发起一次导入；导入失败时保持原始 Markdown，不删除用户内容，并显示可读错误状态。
- 图片复制完成后不依赖原文件路径，因此源文件移动、改名或删除不会影响任务详情中的图片。

## 安全边界

- 不开放任意文件读取接口；IPC 只返回通过图片类型和大小校验的文件。
- 不把本地绝对路径直接写入 `<img src>`，避免 CSP、路径转义和安装环境差异。
- Markdown 文本继续先转义再渲染，不允许用户笔记注入 HTML 或脚本。

## 测试与验收

1. 详情页存在提醒折叠组件，四种方式显示正确的条件字段并生成兼容的提醒对象。
2. 提醒修改通过详情页自动保存，单次过去时间和每周空星期不能提交。
3. `![[C:\\Users\\DELL\\Desktop\\论文阅读步骤.png]]` 能被识别并导入为应用图片引用。
4. 非绝对路径、非图片文件、超出大小限制或不存在的文件不会被读取，原始笔记不会丢失。
5. 导入后的图片可在重新打开任务后继续显示，已有 `deepstudy-image://` 图片不受影响。
6. 中英文界面均显示对应的提醒标签、验证信息和图片导入错误信息。
7. 完整自动测试、Windows 打包和桌面快捷方式验证通过后再发布。

## 不在范围

- 不新增账号、云同步或跨设备图片同步。
- 不提供任意附件管理器或图片编辑功能。
- 不改变长期任务提醒的后台调度频率与系统通知样式。
